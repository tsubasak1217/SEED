# 単位規約（わらしべフィッシング / SEED ランタイム）

このドキュメントは、ゲーム内で使う**距離・サイズ・時間の単位**を定めた正典である。
新しいパラメータを足すときは、必ずここの規約に合わせること
（合わない値を持ち込む場合は、まずこのドキュメントを更新してから実装する）。

## 1. ワールド単位

| 対象 | 単位 | 備考 |
| --- | --- | --- |
| ワールド座標・スケール・距離 | **1 ユニット = 1 メートル (m)** | Transform.Position / 距離計算 / 速度 (m/s) すべて |
| 時間 | **秒 (s)** | `deltaTime`・各種 `xxxSeconds`・BPM から求める拍の長さ |
| 角度 | 度 (deg) | スクリプト API の引数はすべて度。内部で必要なときだけラジアンへ |

インスペクタに公開するフィールドは、単位が自明でないものに限り
ラベルへ単位を書く（例: `"餌の感知距離(m)"` / `"寄せ速度の上限(m/秒)"` / `"基準サイズ(cm)"`）。

### 既知の未調整点（重要）

**既存モデルのスケールはこの規約に合わせていない。**
プレイヤーや魚のモデルは「見た目の収まり」で倍率を決めており
（例: Player は約 4.6 倍のスケールで置かれている）、
モデルの見かけの大きさは実寸 (m) と一致しない。

- ワールド上の**距離・速度**はすべて m として一貫している（キャスト距離・感知距離・巻き速度など）。
- **モデルの見た目の大きさ**だけが未調整。合わせ込むときはモデル側のスケールを直す作業になるが、
  カメラ・当たり判定・演出距離が総取っ替えになるため、単位統一の作業とは切り離す。

## 2. 魚のサイズ

魚の「大きさ」は**釣果として見せる体長**であり、ワールドのスケールとは独立している。

| 項目 | 置き場所 | 単位 |
| --- | --- | --- |
| 基準サイズ（その魚種の標準体長） | `Fish.baseSizeCm`（インスペクタ「基準サイズ(cm)」） | **cm** |
| 個体差の倍率 | `Fish.SizeMultiplier`（生成時に 1 度だけ抽選） | 無次元 |
| 表示サイズ | `Fish.DisplaySize` = `baseSizeCm × SizeMultiplier` | **cm** |
| 自己ベスト | セーブキー `best_size:<表示名>`（`FishRecords`） | **cm** |

### 表示書式

サイズを文字にする箇所は**必ず `Fish.FormatSize(float sizeCm)` を通す**（書式の唯一の実装）。

- 100 cm 未満 … `32.5cm`（小数第 1 位）
- 100 cm 以上 … `1.2m`（cm を m へ換算し小数第 1 位）

参照箇所: 釣果パネル（`CatchPresenter` → `ResultPanel`）、図鑑カード（`ZukanCard`）、
釣りログ（`FishingController`）。

### 戦闘力係数

旧「大きさ（無次元）」は `Fish.powerScale`（インスペクタ「戦闘力係数」）へ改名した。
これは**長さではなく戦闘力にだけ効く無次元の係数**で、既定は 1。
戦闘力の算出式は `FishingFight.SizeScore()` の 1 か所だけに置く
（個体差の倍率 → 0.9〜1.1 へ線形写像 × `powerScale`）。魚側に式を複製しないこと。

## 3. 釣りの距離

やり取り（`FishingFight`）中に出てくる距離はすべて **m**。

| 値 | 意味 |
| --- | --- |
| 実測距離 `FishingController.CurrentFloatDistance()` | ウキ → 竿先の水平距離。**HUD の残り距離表示はこれ** |
| `FishingFight.DesiredFloatDistance` | 魚 HP から求める「いまウキが居るべき距離」＝ 内部のウキ目標位置。**表示には使わない** |
| `metersPerHp` | 魚 HP 1 あたりの距離。HP ⇔ 距離の唯一の換算係数 |
| `reelInSpeedMax` | ウキが手元へ寄る速度の上限 (m/s)。**1 フレームの巻き取り量の上限もこれ**（`FishingFight.ThrottleReelAmount`） |
| `catchDistanceMeters` | 釣り上げが成立する竿先までの距離（`FishingController`） |

### 表示と判定の一致

1. 巻き取り入力（ホイール）は 1 フレームにまとめて飛び込むので、
   `FishingFight.ThrottleReelAmount` が `reelInSpeedMax × deltaTime` で頭打ちにし、
   余りは次フレーム以降へ繰り越す（入力は捨てない）。
   これで「魚 HP の減り」「ウキの実移動」「距離表示」が同じ速度で進む。
2. 釣り上げ成立は **「魚 HP が 0」かつ「実測距離が `catchDistanceMeters` 以下」**の両方。
   HP が先に 0 になった魚は抵抗をやめ（拍・出題・糸の消耗が止まる）、
   ウキは `reelInSpeedMax` で竿先まで寄り続けるので必ず成立する。
   逆に距離だけ詰まっても HP が残っていれば釣れない。

## 4. チュートリアル

進捗表示（`MoveMission` / `ReelMission`）の「あと X m」も同じ実測距離 (m)。
サイズを出す場合は `Fish.FormatSize` を通すこと。
