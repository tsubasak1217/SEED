# エディタ操作ショートカット

SEED エディタのキーボード／マウス操作の一覧。
**ビューポート（シーンビュー）にフォーカスがあるとき**の操作が中心で、
スクリプトエディタやインスペクタのテキスト入力中はコントロール既定の動作が優先される。

## 入力がどこで処理されるか（実装メモ）

埋め込みモードのビューポートは、WPF の `HwndHost` に貼り付けたランタイム（Rust/winit）の
子ウィンドウである。この子ウィンドウは **Edit 中はキーボードフォーカスを持たない**
（Play 開始時だけ `SetFocus` する）。そのため:

- **キーボード**: エディタの低レベルキーフック（`MainWindow.Input.cs::LLKeyboardCallback`）が
  拾い、IPC でランタイムへ転送する（`CAM_KEY_DOWN` / `UNDO` / `MODAL:*` / `TOOL_HOTKEY:*` など）。
- **マウス**: カーソル下のウィンドウへ OS が直接配送するため、ランタイム側の
  `event_handler.rs` / `drag_handler.rs` がそのまま受け取る。
  ただし**カーソルがビューポートの外に出ると配送が止まる**ため、
  「パネル外でも続けたい操作」（モーダルトランスフォーム）はエディタ側の
  低レベルマウスフックでグローバルに追跡して IPC で送る
  （`MainWindow.ModalTransform.cs` / `MODAL:CURSOR:*`）。

新しいキーボードショートカットを足すときは **エディタ側のフック**に書くこと
（ランタイムの `on_keyboard_input` は単体起動時とインプレース Play 中しか動かない）。

## モーダルトランスフォーム（Blender 風）

アクタを 1 つ以上選択した状態で、3D ワールドビューにマウスカーソルがあるときに使える。
ギズモを掴まずにキー 1 つで移動・回転・拡縮を始められる。

| キー | 動作 |
| --- | --- |
| `G` | 移動モーダル開始 |
| `R` | 回転モーダル開始 |
| `S` | 拡縮モーダル開始 |

モーダル中の操作:

| 入力 | 動作 |
| --- | --- |
| マウス移動 | 変形量を決める（下表参照） |
| `X` / `Y` / `Z` | 軸拘束。同じキーを押すたび **ワールド軸 → ローカル軸 → 拘束解除** と巡回する。拘束中はピボットを貫く線を表示（X=赤 / Y=緑 / Z=青） |
| `Shift` 押下中 | 微調整（感度 1/10） |
| 左クリック または `Enter` | 確定（Undo 1 件として記録。複数選択でも 1 件） |
| 右クリック または `Esc` | 取消（開始時の Transform へ完全復元、Undo には積まない） |

マウス移動の意味:

| モーダル | 軸拘束なし | 軸拘束あり |
| --- | --- | --- |
| `G` 移動 | **カメラに正対する平面**（ピボットの深度）上をマウスに追従して移動 | マウスレイと拘束軸直線の**最近接点**に沿ってスライド |
| `R` 回転 | **ビュー方向（カメラ前方向）を軸**に、ピボットのスクリーン座標まわりのマウス角度変化ぶん回転 | 拘束軸まわりに回転 |
| `S` 拡縮 | **全軸均一**。ピボットのスクリーン座標からのマウス距離比が倍率（開始時 = 1.0） | 拘束軸方向のみ拡縮 |

複数選択時は**全選択アクタの重心がピボット**になり、回転は公転＋自転、
拡縮は位置も含めてピボット基準で行われる（既存の回転／拡縮ギズモと同じ挙動）。

制限:
- 対象は **3D ワールドビューのみ**。2D シーンビュー・アクター編集タブ・
  キャンバス編集タブでは開始しない。
- モーダル中は通常の選択クリック・ギズモドラッグ・カメラ操作・
  ツール切替ホットキーがすべて無効になる。
- インスペクタの表示はモーダル中は更新されず、確定／取消の時点で更新される。

### シーンパネルの外へカーソルを出した場合

Blender と同じく、**カーソルがシーンパネルの外（他のパネル上・エディタの外・
画面の端）へ出ても変形は止まらず、マウス移動に追従し続ける**。

- 座標はビューポート左上を原点とするクライアント座標で扱われ、
  パネル外を表す**負値・幅／高さ超え**の値もそのまま計算に使われる
  （移動レイは線形に外挿されるだけなので破綻しない）。
- 左クリック確定・右クリック取消も**パネル外で効く**。
  モーダル中の左クリックは Blender 準拠でどこを指していても確定になり、
  そのクリックは**エディタの UI へは伝わらない**
  （ボタンやツリー項目が誤って押されることはない）。
  中クリックとホイールもモーダル中は無効化される（ズームでピボットの
  スクリーン投影がずれるのを防ぐため）。
- モーダル中に **Alt+Tab などでエディタのフォーカスが外れると自動的に取消**され、
  開始時の Transform へ復元される（裏で変形が進む事故を防ぐ安全側の挙動）。

> **実装メモ**: OS はマウスイベントをカーソル直下のウィンドウにしか配送しないため、
> 子ウィンドウ（ランタイム）はパネル外のマウス移動を受け取れない。そこで
> エディタが**モーダル中だけ**低レベルマウスフック（`WH_MOUSE_LL`、
> `MainWindow.ModalTransform.cs`）を設置してカーソルをグローバルに追跡し、
> `MODAL:CURSOR:{x},{y}` を IPC で送る。ランタイムはこの座標を受け取った時点で
> 「外部座標源」へ切り替え、以降は自前の `CursorMoved` を無視する（二重適用の防止）。
> フックはモーダル終了・フォーカス喪失・例外・ウィンドウ終了のいずれでも解除される。
> 送信は 4ms 間隔で間引くが、確定／取消の直前に最新座標を必ず 1 度送るため
> 最終位置は取りこぼされない。

## ツール切替

| キー | ツール |
| --- | --- |
| `Q` | 選択 |
| `W` | 移動ギズモ |
| `E` | 回転ギズモ |
| `T` | 拡縮ギズモ |

> **変更履歴**: 拡縮は以前 `R` だったが、`R` をモーダル回転へ明け渡したため **`T`** へ移した。

RMB でカメラを操作している間（`Q`/`W`/`E` はカメラの上下・前後移動キーを兼ねる）と
モーダル中は、ツール切替は無視される。

ツールバー右上の `World` / `Local` ボタンでギズモの座標系を切り替える
（モーダルの軸拘束はこのトグルとは独立に、キーの 2 度押しでローカル軸になる）。

## カメラ操作（ビューポート）

| 入力 | 動作 |
| --- | --- |
| 右ドラッグ | 視点回転 |
| 右ドラッグ + `W`/`A`/`S`/`D` | 前後左右へ移動 |
| 右ドラッグ + `Q`/`E` | 下／上へ移動 |
| 右ドラッグ + `Shift` | 移動速度 3 倍 |
| 中ボタンドラッグ | 平行移動（パン） |
| ホイール | ドリー（正射投影中はズーム） |
| 右上の軸ギズモをクリック | その軸方向へスナップ |
| インスペクタ Camera の「デバッグカメラの値を反映」 | 現在のデバッグカメラの位置・向き・FOV・Near/Far・投影方式をそのカメラへコピー（アスペクト比は据え置き／Ctrl+Z 1 回で戻る／Edit モード限定） |

## 編集・ファイル

| キー | 動作 |
| --- | --- |
| `Ctrl+Z` | 元に戻す（地形モード中は地形専用の Undo） |
| `Ctrl+Y` | やり直し |
| `Ctrl+S` | 上書き保存（スクリプトエディタがアクティブならスクリプト保存） |
| `Ctrl+Shift+S` | 名前を付けて保存 |
| `Ctrl+C` | コピー（プロジェクトパネル: アセット / ビューポート: アクタ複製） |
| `Ctrl+V` | 貼り付け |
| `Ctrl+X` | 切り取り（プロジェクトパネルのみ） |
| `Del` / `Esc` | 選択アクタの削除（確認ダイアログあり） |
| ヒエラルキー右クリック → アクタを追加 → ロジック配置 | 円形・グリッド・直線・ランダムのパターンでアクタ群を一括生成する（詳細は `docs/editor_logic_placement.md`） |

### ロジック配置の配置モード（「配置」ボタンを押した後）

| 操作 | 動作 |
| --- | --- |
| マウス移動 | カーソル下の表面（メッシュ・地形。無ければカメラ前方 10m）にプレビューが追従 |
| 左クリック | 確定（Undo 1 件・生成した全アクタが選択される） |
| 右クリック または `Esc` | 取消（何も生成しない） |

> モード中はカメラ回転（右ドラッグ）・ズーム・ギズモ・選択クリック・
> モーダルトランスフォームがすべて無効になる。
> Play 開始・シーン切り替えでは自動的に取り消される。

> `Esc` はモーダルトランスフォーム中・ロジック配置の配置モード中は**取消**として
> 優先的に処理され、削除ダイアログは出ない。
