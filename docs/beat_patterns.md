# ビートパターン記法（釣りバトル）

わらしべフィッシングの釣りバトル（リズム）で、魚が出題する打点の並びを書くための
**レベルデザイン用テキスト**の仕様。

- 置き場所: `projects/WarashibeFishing/assets/mainGame/rhythm/beat_patterns.txt`（UTF-8）
- 読み込み: `FishingFight` の「パターンのファイル」欄（既定で上のパス）
- 実装: `projects/WarashibeFishing/assets/mainGame/scripts/Rhythm/`
  （`BeatPatternParser` が記法の解釈、`BeatPatternLibrary` が読み込みと抽選）

---

## 1. 1 行の書き方

```
{1/4}t,,t,,  {1/6},,,{1/4}t,,  [1-3,5]   # 行末までコメント
```

| 記号      | 意味 |
| --------- | ---- |
| `{1/n}`   | これ以降のカンマ 1 つが **1/n 音符**（小節を 1.0 としたとき 1/n の長さ）になる |
| `,`       | いま有効な音価で時間を 1 単位進める |
| `t`       | **直後のカンマ**が表す音価の**先頭**で叩く（トリガ） |
| `[...]`   | この行を使う魚のレベル帯（省略で全レベル。→ 2 章） |
| `#`       | 以降は行末までコメント |
| 空白      | どこに入れてもよい（読みやすさのためだけ） |
| 空行      | 無視される |

- **カンマの合計が 1.0 で 1 小節**。
  `{1/4},,,,` = 4 分音符 4 つ = 1 小節、`{1/6},,,{1/4},,` = 3/6 + 2/4 = 1 小節。
- `{1/4}t,,t,,` は 1 拍目と 3 拍目（4 拍子の場合）。
- 音価は行の途中で何度でも変えられる。1 小節の中で混ぜてもよい。
- **1 行 ＝ 戦闘サイクル 1 周ぶん**。既定は 2 小節
  （`FishingFight` の「出題の小節数」で決まる）。

### 例

```
{1/4}t,,t,,t,,t,,                  # 各小節の 1・3 拍目（2 小節）
{1/4}t,,t,,{1/8}t,,t,,t,,,,        # 1 小節目は 4 分、2 小節目は 8 分
{1/6}t,,t,,t,,{1/4}t,,t,,          # 3 連符 → 4 分
{1/6}t,t,,{1/4}t,,t,,t,,           # 1 小節の中で 1/6 と 1/4 を混在
```

## 2. レベル帯 `[...]`

その行を使う魚のレベル（`Fish.Level`＝1〜10）を指定する。**カンマ区切りで範囲と単独を混在できる**。

| 書き方      | 意味 |
| ----------- | ---- |
| `[1-3]`     | Lv1〜3 |
| `[1-3,5]`   | Lv1〜3 と Lv5 |
| `[5]`       | Lv5 のみ |
| `[3-]`      | Lv3 以上 |
| `[-2]`      | Lv2 以下 |
| `[*]` / 省略 | 全レベル |

- 範囲外の値・行どうしの重複は**許容**する（レベル上限を知らなくても書ける）。
- 角括弧は 1 行に 1 組だけ。位置はどこでもよいが、末尾に置くのが慣例。

### 抽選の順序

1. 魚のレベルに**該当する行**が 1 行以上あれば、その中から抽選する
2. 1 行も無ければ、**全レベル行（`[*]`／省略）**から抽選する
3. それも無ければ、**フォールバック**（各拍の頭を叩くだけ）を合成し、警告ログを出す

抽選の単位は `FishingFight` の「サイクルごとに抽選する」で切り替える。

- ON（既定）… 出題フェーズのたびに引き直す（1 戦のあいだに譜面が変わる）
- OFF        … 1 戦につき 1 度だけ引き、同じ譜面を繰り返す

## 3. エラーになる行と、そのときの挙動

行単位で検証し、**エラーの行だけを捨てて**警告ログ（行番号つき）を出す。
1 行の誤記でファイル全体が使えなくなることはない。

| エラー | 例 |
| ------ | -- |
| 音価の合計が小節の整数倍でない | `{1/4}t,,,`（3/4 小節） |
| 想定小節数と違う | 2 小節想定のところに `{1/4}t,,,,`（1 小節） |
| 音価が未指定のままカンマが来た | `t,,,,` |
| `t` が連続している／行末に残った | `{1/4}tt,,` `{1/4}t,,,,t,,,t` |
| 解釈できない文字がある | `{1/4}t,,x,,` |
| 音価の書式違い・分子が 1 でない・分母が 1〜64 の外 | `{4},,` `{2/4},,` `{1/128},,` |
| 角括弧が閉じていない／2 組以上ある | `... [1-3` |
| レベル帯が数値でない／下限 > 上限 | `[a-3]` `[5-2]` |

ログは `[BeatPattern] <パス> <行番号> 行目: <理由>` の形。
多すぎるときは先頭 10 件だけ出し、残りは件数だけ知らせる。

## 4. ホットリロード

- ファイルの**更新時刻を 1 秒ごとに確認**し、変わっていれば読み直す。
- 確認するのは**戦闘していないあいだだけ**なので、
  反映されるのは必ず**次の戦闘から**（進行中の譜面は途中で入れ替わらない）。
- エディタで Play したまま `beat_patterns.txt` を保存 → 次に魚を掛けた時点で新しい譜面になる。

## 5. テンポと隙（Rest）の BPM

| 区間 | テンポ |
| ---- | ------ |
| 余白（LeadIn）・出題（Call）・回答（Answer） | **魚固有の BPM**（`Fish` の「BPM」） |
| 隙（Rest） | **`FishingFight` の「隙のBPM」**（既定 100） |

- 隙の長さは従来どおり小節数で決める（完璧 2 小節／通常 1 小節・インスペクタ）。
  変わったのは「1 小節の実時間」だけで、それを隙専用 BPM で数える。
- 隙のあいだはドラムループの再生速度もこの BPM へ同期し、
  戦闘（余白・出題・回答）へ戻ると魚の BPM に戻る。
- 漂流物「ひるませ」による隙の延長も、この隙の小節長で秒に換算される。

### 拍子

拍子（1 小節の拍数）は **`FishingFight` の「拍子(1小節の拍数)」**（既定 4）に一本化した。
ビートパターンは「小節を 1.0 とした位置」で書くので拍子には依存しないが、
メトロノームの強拍・ドラムの小節線・開始時の余白の拍数はこの値で決まる。

> 2026-09-09 の改定で、`Fish` の「拍子」「リズムパターン」「隙の小節数」は**廃止**した。
> 魚固有のリズム設定は **BPM だけ**である。
