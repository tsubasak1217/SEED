# SEED スクリプトデバッガ（内蔵・netcoredbg）

エディタからスクリプト（C#）を **ブレークポイントで停止して** デバッグする機能です。
実行中のランタイム（SEED.exe）へ [netcoredbg](https://github.com/Samsung/netcoredbg)（OSS の .NET デバッガ・DAP 対応）でアタッチします。

スクリプトは埋め込み PDB 付きでコンパイルされるため、ソース行と実行コードが対応づき、
`.cs` に張ったブレークポイントで停止できます。

---

## セットアップ（netcoredbg の配置）

netcoredbg のバイナリはサイズが大きいためリポジトリには含めていません。次のいずれかで配置してください。

1. **リポジトリ内に置く（推奨）**: [Releases](https://github.com/Samsung/netcoredbg/releases) から Windows 版を入手して展開し、
   `tools/netcoredbg/netcoredbg.exe` に置く（リポジトリ直下 or エディタ実行ディレクトリから親を遡って探します）。
2. **環境変数**: `SEED_NETCOREDBG` に `netcoredbg.exe` のフルパスを設定する。
3. **PATH**: `netcoredbg.exe` を PATH の通ったフォルダに置く。

見つからない場合はアタッチ時にメッセージで案内します。

---

## 使い方

1. **Play** でゲームを実行する（スクリプトは Play 中のランタイム内で動きます）。
2. スクリプトエディタで、行番号の左のガターをクリックして **ブレークポイント**（赤丸）を置く。
3. メニュー **［デバッグ］→［内蔵デバッガでアタッチ］** を実行 → ランタイムへアタッチし、ブレークポイントを設定します。
4. その行に処理が来ると **停止** し、エディタが該当行を表示します。
5. ［デバッグ］メニューから **継続 / ステップオーバー / デタッチ** ができます。

> 停止中はスクリプトがランタイムのメインスレッドで止まるため、**ゲーム画面も一時停止**します（通常のデバッグ挙動です）。デタッチしてもランタイムは終了しません。

## 現状と今後（ロードマップ）

- ✅ 置場 UI（ガターのブレークポイント・行追従・永続化）
- ✅ netcoredbg 組込＋DAP クライアント（アタッチ・setBreakpoints・継続・ステップオーバー・停止行表示）
- ⏳ 停止行のハイライト（現在行の矢印表示）
- ⏳ コールスタック / ローカル変数 / ウォッチ パネル
- ⏳ ステップイン・アウト、一時停止、条件付きブレークポイント・ログポイント

技術構成: `editor/src/Debugger/`（`DapClient` = DAP プロトコル、`ScriptDebugSession` = アタッチ手順と操作、`NetcoredbgLocator` = 実行ファイル探索）。ブレークポイントは `editor/src/Panels/ScriptEditor/Breakpoint*.cs` が管理し、`editor/settings/breakpoints.json` に永続化されます。
