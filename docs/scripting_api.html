◆SEED スクリプト API リファレンス

基本形 ライフサイクル Time / Debug Mathf Vector / Quaternion / Color Random Input Physics Audio GameObject コンポーネント Scene ライブラリ
重要: SEED は Unity ではありません。UnityEngine / MonoBehaviour / GetComponent は存在しません。 エンジン API（Mathf / Vector3 / Time など）は SEED 名前空間にあり、 コードでは必ず SEED. を付けて呼び出します（例: SEED.Random.Range(0, 10)）。 本ページの一覧部分は簡潔さのため SEED. を省略しています。

1. スクリプトの基本形

C# で書き、SEEDScript（SEEDEditor.Scripting 名前空間）を継承します。

using SEEDEditor.Scripting;   // SEEDScript・[SerializeField]・NativeFrameContext

public class Mover : SEEDScript
{
    // インスペクタに公開するフィールドは [SerializeField] を付ける
    [SerializeField(Label = "速度")]
    private float speed = 2.0f;

    public override void Update(ref NativeFrameContext ctx)
    {
        // 毎フレーム、自分の GameObject を右へ動かす
        transform.Position += SEED.Vector3.Right * speed * SEED.Time.DeltaTime;
    }
}
[SerializeField]フィールドをインスペクタに公開する属性。Label / Tooltip 指定可
ref NativeFrameContext ctxctx.DeltaTime（前フレームからの経過秒）と ctx.AnimTime（累計時間）を持つ
無修飾で書きたい場合はスクリプト先頭に自分で using SEED; を足します（System.Random 等との型名衝突は自己責任）。

インスペクタ公開の属性（SEEDEditor.Scripting 名前空間）

フィールドやクラスに付ける属性。すべて using SEEDEditor.Scripting;（テンプレートに含まれる）だけで使えます。

属性付ける先効果
[SerializeField]フィールドインスペクタに公開する。Label = "表示名" / Tooltip = "説明" を名前付き引数で指定できる（省略時のラベルはフィールド名を整形したもの）
[Header("見出し")]フィールドそのフィールドの直前に見出し行を挿入する
[Tooltip("説明")]フィールドマウスオーバー時の説明。[SerializeField(Tooltip = ...)] より独立した [Tooltip] が優先される
[Range(min, max)]フィールド数値フィールドをスライダー表示にする（float / int）
[RequireComponent(typeof(OtherScript))] / [RequireComponent("Camera")]クラスアタッチ時に不足コンポーネントを自動追加する。型指定＝他スクリプト（型名から .cs を探す）、文字列指定＝ネイティブコンポーネント名
[DisallowMultipleComponent]クラス同一アクターに同じスクリプトを 2 つ以上付けられなくする（追加操作が警告で中止される）
[RequireComponent("Camera")]
[DisallowMultipleComponent]
public class CameraShake : SEEDScript
{
    [Header("揺れ")]
    [SerializeField(Label = "強さ")]
    [Range(0f, 5f)]
    private float amplitude = 1.0f;

    [SerializeField]
    [Tooltip("1 秒あたりの振動回数")]
    private float frequency = 8.0f;
}

[Serializable] を付けたクラス／構造体型のフィールドに [SerializeField] を付けると、インスペクタで子フィールドが再帰的に展開されます（入れ子の上限は 8 段）。

2. ライフサイクル関数

SEEDScript を継承して override。1 フレーム内で以下の順に呼ばれます。不要なものは override 不要。

BeginFrame(ref ctx)フレーム開始時。入力取得や状態リセット向け
EarlyUpdate(ref ctx)Update より前。他スクリプトへ渡す事前計算向け
Update(ref ctx)毎フレームの主更新。ゲームロジックの中心
ConstantUpdate(ref ctx)固定タイムステップの更新。物理など時間刻みを一定にしたい処理向け
LateUpdate(ref ctx)Update 後。追従カメラなど他更新の結果を使う処理向け
Render(ref ctx)描画フェーズ。描画に関わる処理向け
EndFrame(ref ctx)フレーム終了時。後片付けや状態確定向け

物理イベントコールバック（3D / 2D 共通）

自分のコライダー（ColliderComponent / Collider2dComponent）が他コライダーと衝突・接触すると呼ばれます。other は相手アクター（特定できない場合 IsValid == false）。

OnCollisionEnter(GameObject other)衝突が始まったフレーム
OnCollisionStay(GameObject other)衝突継続中（毎物理ステップ）
OnCollisionExit(GameObject other)衝突が終わったフレーム
OnTriggerEnter(GameObject other)トリガーへの進入時（トリガー側・相手側の両方に通知）
OnTriggerExit(GameObject other)トリガーからの退出時（同上）
public class Coin : SEEDScript
{
    public override void OnTriggerEnter(SEED.GameObject other)
    {
        SEED.Debug.Log($"取得: {other.IsValid}");
        gameObject.Destroy();   // 自分を消す
    }
}

4. Mathf（数学ユーティリティ・float 中心）

定数

Mathf.PI / Deg2Rad / Rad2Deg / Epsilon / Infinity / NegativeInfinity円周率、度⇄ラジアン変換係数、微小値、正/負の無限大

三角関数・指数対数

Mathf.Sin(x) / Cos(x) / Tan(x)三角関数（ラジアン）
Mathf.Asin(x) / Acos(x) / Atan(x) / Atan2(y, x)逆三角関数。Atan2 は象限を考慮した角度
Mathf.Sqrt(x) / Pow(x, p) / Exp(x)平方根・べき乗・指数
Mathf.Log(x) / Log(x, b) / Log10(x)自然対数・底指定対数・常用対数

丸め・符号

Mathf.Abs(x) / Sign(x)絶対値・符号（-1/0/1）
Mathf.Floor(x) / Ceil(x) / Round(x)切り捨て・切り上げ・四捨五入（float を返す）
Mathf.FloorToInt(x) / CeilToInt(x) / RoundToInt(x)同上（int を返す）

範囲・補間

Mathf.Min(a, b) / Max(a, b)最小値・最大値
Mathf.Clamp(v, min, max) / Clamp01(v)範囲に収める（Clamp01 は 0〜1）
Mathf.Lerp(a, b, t) / LerpUnclamped(a, b, t)線形補間（t は 0..1 にクランプ / クランプなし）
Mathf.InverseLerp(a, b, v)v が a〜b のどの割合かを返す（Lerp の逆）
Mathf.MoveTowards(current, target, maxDelta)target へ最大 maxDelta ずつ近づける
Mathf.Repeat(t, length) / PingPong(t, length)ループ（0〜length）/ 往復（0→length→0）
Mathf.SmoothStep(from, to, t)滑らかなイーズイン・アウト補間
Mathf.Approximately(a, b)浮動小数の等価比較（== の代わりに使う）

Abs / Min / Max / Clamp には int 版のオーバーロードもあります（Mathf.Clamp(i, 0, 9) は int を返す）。
Mathf.Epsilon は 1e-6f（.NET の float.Epsilon とは別物）。Approximately はこれを基準に相対誤差で比較します（許容差 = max(Epsilon × max(|a|,|b|), Epsilon × 8)）。

6.6 Physics（レイキャスト・キャラクター移動）

Physics.Raycast(origin, dir, maxDistance, out hit)bool: 最初にヒットしたコライダーの情報を hit に格納
Physics.Raycast(origin, dir, maxDistance)bool: ヒット情報が不要な場合の簡易版
hit.GameObjectGameObject: ヒットしたアクター（IsValid で有効判定）
hit.PointVector3: ヒット点のワールド座標
hit.NormalVector3: ヒット点の法線
hit.Distancefloat: 始点からの距離
if (SEED.Physics.Raycast(transform.Position, SEED.Vector3.Down, 10f, out var hit))
{
    SEED.Debug.Log($"接地: {hit.Point} 距離={hit.Distance}");
}
3D 物理（ColliderComponent）に対するレイキャストです。物理スレッドへの同期問い合わせのため、毎フレーム大量に呼ぶとフレーム時間を消費します。衝突・トリガーのイベント通知は第 2 節の物理イベントコールバックを参照。

キャラクターコントローラー（Transform を書くだけで地形に押し戻される）

Collider インスペクタの「キャラクターコントローラー」を ON にしたアクターは、専用 API を呼ばず transform.Position を書き換えるだけで地形・静的コライダーに衝突解決され、めり込んだぶんが自動で押し戻されます。押し戻しは移動のたびではなく 物理ステップ同期（60Hz）と同じタイミングで前回位置との差分を解決します。壁ずり・段差・スロープは内部の KCC が処理します。

Physics.IsGrounded(gameObject)bool: キャラクターが接地しているか（物理ステップ同期で自動更新）
transform.Teleport(pos)void: 衝突を無視して pos へ瞬間移動（前回位置もリセットされ押し戻されない）
// キャラクター移動: Position を希望位置へ書くだけ。地形にめり込めば押し戻される
velocityY += -9.81f * SEED.Time.DeltaTime;                // 重力は自前で積分
if (SEED.Physics.IsGrounded(gameObject) && velocityY < 0f) velocityY = 0f;
transform.Position += horizontal + new SEED.Vector3(0f, velocityY, 0f) * SEED.Time.DeltaTime;
対象は Collider（カプセル推奨）を持ち、インスペクタで「キャラクターコントローラー」を ON にしてください。1 フレーム内で Position を何度書いても物理ステップで 1 回だけまとめて解決されます（反映に 1 フレームの遅延あり）。補正後の位置は集約経路で反映され子アクタも追従します。重力・複数移動の合成はスクリプト側の責務です。瞬間移動は transform.Teleport() を使ってください。

6.7 Audio（BGM・効果音）

ファイルは assets:// 仮想パスで指定（対応形式: wav / ogg / mp3 / flac）。

Audio.Play("assets://sounds/shoot.wav")効果音を再生（多重再生可・音量 1.0）
Audio.Play("assets://sounds/hit.ogg", 0.5f)音量指定で効果音を再生
Audio.PlayBgm("assets://sounds/stage1.ogg")BGM を再生（既存 BGM は停止して置き換え。既定でループ）
Audio.PlayBgm(path, 0.8f, loop: false)音量・ループ指定で BGM を再生
Audio.SetBgmVolume(0.3f)BGM 音量を変更
Audio.StopBgm()BGM を停止
同じファイルはキャッシュされ、2 回目以降の再生でディスク読み込みは発生しません。オーディオデバイスが無い環境では全操作が無音で無視されます。アクターに紐づく音源（3D 距離減衰・パン）は AudioSource コンポーネント（第 7 節）を使ってください。

7. GameObject

スクリプトは自分がアタッチされた GameObject を gameObject、その Transform を transform（短縮）で参照できます。コンポーネントは gameObject.GetComponent<T>() で取得します。戻り値は T?（Nullable）で、未アタッチ・該当なしは null。SEED のアクターは同種を複数スロット持て、スロットには名前があります。

gameObjectGameObject: このスクリプトが乗るオブジェクト
gameObject.IsValidbool: 実体が有効か
gameObject.HasComponent("Sprite")bool: 指定名のコンポーネントを持つか

HasComponent(name) の名前: 受け付ける文字列は Transform / CanvasTransform / Sprite / Camera / Audio（AudioSource ではなく Audio）/ Animator / ParticleEmitter / InputMap の 8 つで、それ以外は常に false です。型で判定できる場面では GetComponent<T>() is { } のほうが安全です。

transformTransform: gameObject.GetComponent<Transform>() の短縮
gameObject.GetComponent<T>()T?: 0 番目のスロット（未アタッチは null）。T = Transform/CanvasTransform/Sprite/Camera/AudioSource/Animator/ParticleEmitter/InputMap
gameObject.GetComponent<T>(index)T?: index 番目のスロット
gameObject.GetComponent<T>("Name")T?: スロット名一致
// null 合体・パターンで安全に使う（Unity と違い戻り値は Nullable）
if (gameObject.GetComponent<Sprite>() is { } sprite)
{
    sprite.Color = SEED.Color.Red;
}

生成・破棄・検索（Instantiate / Destroy / Find）

GameObject.Instantiate("assets://actors/Bullet.actor").actor ファイル（プレハブ）からアクターを生成。戻り値に同フレーム中に Position 等を設定でき、その値が優先される
obj.Destroy() / GameObject.Destroy(obj)アクターを破棄（実際の破棄はフレーム末尾。Unity と同じ遅延モデル）
GameObject.Find("Player")アクターを名前で検索（ヒエラルキーの DFS 順で最初の一致）
var bullet = SEED.GameObject.Instantiate("assets://actors/Bullet.actor");
if (bullet.GetComponent<Transform>() is { } bt)   // 生成直後に位置設定できる
    bt.Position = transform.Position;
if (!bullet.IsValid) { /* 読み込み失敗 */ }

var player = SEED.GameObject.Find("Player");
if (player.GetComponent<Transform>() is { } pt) { pt.Position = SEED.Vector3.Zero; }
2D アクター（Actor2D）の注意: 構築時に Transform が CanvasTransform へ差し替わるため、生成直後の 3D Position 設定は反映されません。位置は翌フレーム以降に CanvasTransform.Position で設定してください。
破棄済み GameObject への読み取りは既定値、書き込みは無視されます（クラッシュしません）。
現時点の制限: Play 開始後に生成・破棄したアクターの物理コライダーは物理スレッドに反映されません。コライダーの収集は Play 開始時（およびシーン遷移時）の一括処理で、Instantiate / Destroy は物理側の追加・除去を行わないためです。衝突・トリガーのイベント通知自体は実装済みですが（第 2 節）、実行時に生成したアクターはその対象になりません。

7.x コンポーネント

Transform（3D 位置・回転・スケール）

transform.PositionVector3（get/set）。ワールド絶対座標
transform.WorldPositionVector3（get のみ。ワールド絶対座標 = Position と同値）
transform.RotationVector3（get/set。YXZ オイラー角・度）
transform.ScaleVector3（get/set）
transform.Teleport(pos)void: 衝突を無視して pos へ瞬間移動（キャラクターコントローラー用。前回位置もリセットし押し戻されない）
// 例: 回しながら上げる
transform.Rotation += new SEED.Vector3(0f, 90f * SEED.Time.DeltaTime, 0f);
transform.Position += SEED.Vector3.Up * SEED.Time.DeltaTime;

親子の追従: Transform の各値はワールド絶対座標です。スクリプトから Position / Rotation / Scale のいずれかを書き込むと、その差分が自身のメッシュと全子孫アクター（Transform とメッシュの両方）へ即座に伝播します。モデルを持たない子アクター（カメラなど）も追従します。代入した直後に子の Transform を読めば更新後の値が返ります。なおアニメーション・物理による Transform 更新はこの伝播経路を通りません（既知の制限）。

CanvasTransform（2D キャンバス上の位置・回転・スケール）

ct.PositionVector2（get/set。親 Canvas 基準の相対座標）
ct.Rotationfloat（get/set。Z 軸周りの度）
ct.ScaleVector2（get/set）
ct.PivotVector2（get/set。回転・スケール基準点。正規化 [0,1]、(0.5,0.5)=中央）
ct.AnchorVector2（get/set。親 Canvas 内の position 基準点。(0,0)=左上 (1,1)=右下）
ct.ScreenPositionVector2（get のみ。ウィンドウ左上原点のスクリーン座標・ピクセル。アンカー・スケールモード・親チェーンをすべて反映した絶対位置）

Sprite（2D スプライト表示）

sprite.TexturePathstring（get/set。assets:// 仮想パス。空文字=単色表示）

cam.Projectionstring（get/set。"perspective" / "orthographic"）
cam.OrthoHeightfloat（get/set。正射投影時の縦の描画範囲・ワールド単位。横は OrthoHeight × アスペクト比）

AudioSource（アクター紐づけの音源。3D 距離減衰・パン対応）

エディタの「コンポーネント追加 → サウンド → Audio Source」で追加し、インスペクタで設定します。

audio.Play()設定された音源を再生（再生中なら鳴らし直し）
audio.Stop()停止
audio.IsPlayingbool: 再生中か
audio.Pathstring（get/set。assets:// 仮想パス）
audio.Volumefloat（get/set。1.0=等倍。再生中も即反映）
audio.Loopbool（get/set。次回 Play 時に反映）
audio.PlayOnStartbool（get/set。Play 開始時に自動再生）
audio.Spatialbool（get/set。3D 空間再生 = メインカメラとの距離減衰 + 方向パン）
audio.MinDistance / audio.MaxDistancefloat（get/set。減衰開始距離 / 無音距離。減衰は線形）
audio.Panfloat（get/set。-1=左 〜 1=右。Spatial=false 時のみ有効）

Animator（キーフレームアニメーション再生）

エディタの「コンポーネント追加 → アニメーター」で追加し、インスペクタで再生対象クリップ（clips）を登録します。トラック評価・書き込みはエンジン側の AnimationSystem が毎フレーム自動で行うため、スクリプトからは再生の開始・停止・状態参照のみ行います。

anim.Play("Walk")指定クリップを先頭（time=0）から再生（速度は変更しない）
anim.Play("Walk", 1.5f)再生速度も同時に指定して再生
anim.Stop()停止して time=0 に戻す
anim.Pause()再生位置を保持したまま一時停止
anim.Resume()一時停止を再開（再生対象クリップが無ければ無視）
anim.IsPlayingbool（get のみ。再生中か）
anim.CurrentClipstring（get のみ。再生中のクリップ名。未再生は空文字）
anim.Timefloat（get/set。再生位置・秒。書き込みでシーク可能）
anim.Speedfloat（get/set。再生速度倍率。1.0=等倍、負値で逆再生）
Play で指定するクリップ名は、そのアクターの Animator に登録済み（clips 一覧に存在し、既にロード済み）である必要があります。未登録・未ロードの名前を指定すると警告ログを出して無視されます（例外は発生しません）。クリップは Play モード開始時（初回フレーム、スクリプトの Update 等より前）に自動ロードされます。

ParticleEmitter（GPU パーティクル放出源）

エディタの「コンポーネント追加 → パーティクルエミッタ」で追加し、インスペクタで放出パラメータを設定します。放出位置・向きは同じ GameObject の transform が決めます。

ps.Play()放出を開始（playing = true）
ps.Stop()放出を停止（既存パーティクルは寿命で消える）
ps.Burst(50)50 個を即時一括放出（継続放出とは独立。次フレームで消費）
ps.IsPlayingbool（get のみ。放出中か。Playing の別名）
ps.Playingbool（get/set。放出中フラグ。Play()/Stop() と同じ切り替え）
ps.EmitRatefloat（get/set。1 秒あたりの放出個数。負値は 0 にクランプ）
ps.LoopEmitbool（get/set。寿命ループ放出するか）
ps.Dragfloat（get/set。空気抵抗係数。負値は 0 にクランプ）
ps.SpreadAnglefloat（get/set。放出円錐の半頂角・度。0〜180 にクランプ）

InputMap（入力アクションマップ）

エディタの「コンポーネント追加 → 入力 → Input Map」で .inputmap（アクション名 → 物理入力）を割り当て、アクション名で入力を取得します。キーボード（Key）に加えてゲームパッド（GamepadButton / GamepadAxis）を評価します（PC）。

input.GetAction("Jump")bool: 条件（Trigger/Press/Release）適用後の状態
input.GetActionStart("Jump")bool: アクション成立の瞬間のフレームだけ
input.GetActionEnd("Jump")bool: アクション終了の瞬間のフレームだけ
input.GetAxis("Steer")float: Axis1D（[-1,1]。正/負バインドの合成）
input.GetVector2("Move")Vector2: Axis2D（各 [-1,1]。x/y の正負合成。normalize 指定時は正規化）
if (gameObject.GetComponent<InputMap>() is { } input)
{
    var move = input.GetVector2("Move");
    transform.Position += new SEED.Vector3(move.x, 0f, move.y) * 5f * SEED.Time.DeltaTime;
    if (input.GetActionStart("Jump")) { /* ジャンプ */ }
}
アクション条件（Bool）: .inputmap の condition で Trigger（成立の瞬間）/ Press（押下中・既定）/ Release（離した瞬間）を選択。GetAction は条件適用後の状態、GetActionStart/GetActionEnd はその立ち上がり/立ち下がり。
軸: 正バインド − 負バインドを合成して [-1,1] にクランプ。デジタル（Key/GamepadButton）は押下=1.0、アナログ（GamepadAxis）はデッドゾーン適用後の符号付き生値。スティックは正バインドに LeftStickX 等を 1 件で両方向をカバー。Axis2D は normalize で長さ>1 のとき正規化（斜めが 0.707）。
ゲームパッド: GamepadButton = South/East/West/North・DPad*・LeftShoulder/RightShoulder・LeftStickPress/RightStickPress・Start/Select。GamepadAxis = LeftStickX/Y・RightStickX/Y（-1..1）・LeftTrigger/RightTrigger（0..1）。GamepadAxis のみ dead_zone（既定 0.2）が有効。接続パッドは最初の 1 台のみ。
キー名はエディタの選択肢（Space / LeftShift / Q / Alpha0 / Keypad0 / UpArrow …）に対応。マッピング不能な名前は無反応（ロード時に警告 1 回）。
後方互換: 旧 v1（version 欠落・WASD）も読み込め、内部で自動的に v2 へ移行（保存は常に v2）。
.inputmap は初回アクセス時に読み込み・キャッシュ（毎フレーム再読込しません。実行中のファイル編集は反映されません）。
複数持ち: gameObject.GetComponent<InputMap>(1)（index）や gameObject.GetComponent<InputMap>("Vehicle")（名前）で選択。

7.5 Scene（シーン遷移）

シーンはプロジェクト設定 → シーンマネージャで登録した名前で参照します（assets:// パス直接指定も可能）。

Scene.Load("game")事前読み込みのみ（現在のシーンはそのまま）。保持できるのは 1 つで、直後の Transition で消費される
Scene.Transition("game")シーン切り替え。フレーム末尾に行われ、現在のシーンの全アクター・スクリプトは破棄される。Load 済みなら即座、未 Load なら内部で自動読み込み
// 推奨フロー: 事前読み込み → 遷移（遷移フレームのロード時間がなくなる）
SEED.Scene.Load("game");         // フェード中などに呼ぶ
// ... フェードアウト演出など ...
SEED.Scene.Transition("game");   // 即座に切り替わる
読み込みに失敗した場合は現在のシーンが維持されます（戻り値 true は「受理」であり成功保証ではない）。Transition を呼んだフレームで発行した Instantiate / Destroy は破棄されます。シーン遷移を決めたら、そのフレームではそれ以上シーン操作をしないでください。
